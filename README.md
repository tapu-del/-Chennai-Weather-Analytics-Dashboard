# -Chennai-Weather-Analytics-Dashboard
An interactive Power BI dashboard analyzing Chennai weather patterns, temperatures, and precipitation.
## About the Project
This project is an interactive Power BI dashboard built to analyze historical weather data for Chennai. The goal was to visualize temperature trends, rainfall, and weather conditions over time.

## Tools & Skills Used
* Power BI
* Data Cleaning
* Data Visualization
* Dashboard Design (Light Blue & White Theme)

## Key Metrics Analyzed
* **KPI Cards:** Average Max Temperature, Average Min Temperature, Total Precipitation, and Average Wind Speed.
* **Line Chart:** Tracked the maximum and minimum temperature trends over time.
* **Column Chart:** Counted the frequency of different weather types (Rain, Sun, Fog, etc.).
* **Interactive Slicer:** Added a filter to view data by specific weather conditions.
